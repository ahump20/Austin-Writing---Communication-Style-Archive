# Austin Communication Style Canonical Pack

[verified] Current package date: July 7, 2026.

## Purpose

This pack is the portable reference for Austin's communication system. It exists so agents and humans can load the current model without sorting through stale generated viewers, screenshots, raw exports, or duplicate archive surfaces.

North Star: the best communication changes the doorway, not the truth.

Truth-transfer rule: the mechanism has to survive translation. A strong bridge changes metaphor, rhythm, slang, grammar, image, silence, or proof shape without changing the causal architecture underneath.
