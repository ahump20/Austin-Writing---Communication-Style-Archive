# Official X Archive Drop Zone

Put official X/Twitter archive ZIPs here after X makes them available.

Expected examples:

- `a_hump20-twitter-archive.zip`
- `TXTrickWhooper-twitter-archive.zip`

Raw ZIPs are ignored by git. The cleaned parser output belongs in `X-Twitter-Archive/processed/`.

Run from the repo root:

```bash
./scripts/run_official_x_archive_pipeline.sh
```
